# Export Microsoft To Do

There are many ways to export data from Microsoft To Do.

- Graph API
- Web app (IndexedDB)
- Desktop app (SQLite)

## Graph API

The python script `Export_Microsoft_Todo.py` will export all data from Microsoft Todo including task content (as html or markdown) and attachments.

Read the instructions at the top of the file to configure an App Registration in Azure to enable use of the Graph API.
